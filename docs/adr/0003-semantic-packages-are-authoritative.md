# 已发布语义包是业务语义的唯一权威来源

正式分析只能依据人工审核并发布的 `Semantic Version`；PDF、Markdown、数据库注释和对话纠正属于辅助知识，只能帮助检索、解释或生成待审核草稿与 `SemanticChangeProposal`。相比让 RAG 文档直接影响查询，这降低了新知识立即生效的便利性，但避免非结构化内容、提示注入和未经确认的口径静默改变可执行分析。

## Consequences

- 文档中提取出的指标、关系、词汇或策略必须进入 Draft 并通过审核发布后才能影响正式查询。
- 用户纠正不会在线改写已发布语义；当前分析若采用临时假设，必须显式展示该假设。
- 历史分析固定其 Semantic Version，发布内容不可原地修改。
